# Blog articles: "Lab notes"

Five ready-to-paste articles for the **News** blog. Shopify stores blog posts in the admin, not in theme files, so you have to create them by hand.

## How to add one

1. In the Shopify admin, go to **Online Store → Blog posts → Create blog post**.
2. Fill in **Title** from the article file.
3. In the content editor, click **Show HTML** (`<>`) and paste everything below the `---` line of the article file.
4. Under **Excerpt**, paste the excerpt from the article file.
5. Under **Image**, upload the listed file from `images/` and use the alt text from the article file.
6. Set **Blog** to *News*, add the tags, set **Author** to Patrik Jaroš and click **Save** (visible).

Publish them in order 01 → 05. The newest one shows first.
